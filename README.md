MLOps Inference Platform: Architecture & Operations README

1. Project Overview

This document outlines the enterprise architecture, technology stack, infrastructure management, and operational workflows for the scalable MLOps inference platform hosted on AWS EKS (Kubernetes). The platform is designed to securely and reliably host machine learning models packaged as Docker containers, ensuring independent autoscaling, robust monitoring, and automated GitOps deployments.
